# 업무 안내·추적 화면 개선 · 2026-10-10

홈의 방패 로고·먹색 상단·버건디 메뉴를 공통 헤더로 사용합니다. 문서·프로젝트·관리 화면에서도 계정·알림·로그아웃 위치가 같습니다.

## 프로젝트에서 지금 할 일 확인

프로젝트 개요·참여자·설정·타임라인·업무 탭·시험 상세에 **문서 준비 → 품질시험 → 보안 검토 → 최종 배포**를 표시합니다.

- 각 단계는 `완료 / 진행 필요 / 차단`으로 표시합니다. 색상과 함께 텍스트 상태를 제공합니다.
- 단계별 카드 위에 **지금 할 일**을 먼저 보여줍니다. 가장 먼저 해결할 단계와 담당 역할, 해결 화면으로 가는 링크를 표시합니다.
- 문서가 바뀌면 품질·보안 결과의 현재 유효성을 다시 확인합니다. 이전 버전 비교와 재검증 버튼은 유지합니다.
- 품질시험이 적합해도 미해결 부적합이 있으면 품질 단계가 완료되지 않습니다.
- 배포 완료는 현재 구성과 일치하는 실제 미회수 배포 기록이 있을 때 표시합니다. 회수·새 문서 변경 후에는 다시 준비 상태를 보여줍니다.
- 종료된 프로젝트는 기록 조회만 안내합니다. 문서 보안 범위를 충족하지 못한 참여자는 프로젝트 기본 정보와 제한 안내만 보며 검증 상태·사유를 받지 않습니다.

이 단계 안내는 서버의 배포 검사에서 도출합니다. 화면만 보고 배포를 허용하지 않으며, 실제 배포 요청은 기존처럼 프로젝트 잠금 안에서 최신 조건·파일 무결성·수신자 권한을 다시 확인합니다.

## 네 가지 시연

| 문제 | 확인할 화면과 시연 |
| --- | --- |
| 수정 문서와 이전 시험 결과가 섞임 | 검증 완료한 설계서에 v2를 만들고 제출합니다. 최종 배포에서 v1→v2 차이와 재검증 필요 상태를 확인합니다. 품질만 갱신하면 계속 차단되고 보안까지 갱신해야 배포할 수 있습니다. |
| 최신 승인본을 찾기 어려움 | 문서 목록에서 **최신 승인본 보기**를 선택합니다. v2가 초안이어도 v1 승인본을 열 수 있습니다. 문서 상세의 **버전·승인 이력**에서 열람 가능한 최신 버전과 최신 승인본을 비교합니다. v2 승인 후 승인본이 갱신되는지 확인합니다. |
| 배포한 파일과 수신자가 불명확 | 배포 상세에서 고정된 문서 제목·버전·첨부 파일명·해시·수신자·ZIP 내부 경로를 확인합니다. 이후 v2 첨부를 바꿔도 이미 확정한 v1 배포 파일은 그대로입니다. 다운로드 버튼은 지정 수신자와 관리자에게, 회수 버튼은 책임자와 관리자에게 표시합니다. |
| 부적합 해결을 수기로 확인 | 품질시험에서 부적합을 기록합니다. 시험 상세 또는 부적합 화면의 **이 시험 재시험**을 눌러 원시험을 연결합니다. 적합 재시험 후 부적합 화면에서 검증된 재시험 후보를 선택하고 원인·시정 조치를 입력해 종료합니다. 원시험·재시험·시정 조치 링크로 처리 근거를 확인합니다. |

문서 승인본 조회에도 기존 부서·직급·보안·프로젝트 권한이 적용됩니다. 비공개 초안의 제목과 링크는 권한 없는 사람에게 표시하지 않습니다. 보관 포함 옵션으로 찾은 승인 이력은 보관 상태를 함께 표시하며 현재 배포 가능한 문서라고 안내하지 않습니다.

## 시간대 설정

`Instant` 기록은 한국 시간으로 표시합니다. 시간대 없는 기존 `LocalDateTime`은 기본적으로 현재 JVM의 시간대로 저장된 값으로 해석합니다. 다른 시간대의 서버에서 기존 DB를 옮긴 경우, 원래 저장 시간대를 `app.display.legacy-zone`에 지정하세요. 예를 들어 UTC 서버에서 생성한 DB를 한국 PC로 옮겼다면 `--app.display.legacy-zone=UTC`를 사용합니다. 원래 기록에 없던 시간대를 자동으로 추정하지 않습니다.

## 검증 범위

Java 21에서 전체 `build`와 **302개 테스트**가 통과했습니다. 실패·오류·건너뜀은 모두 0건입니다. 실제 Chromium에서도 아래 네 가지 업무 시연과 데스크톱·390px 모바일 화면을 확인했습니다.

- 실제 문서 준비·검증·배포·후속 버전 생성에 따라 단계가 바뀌고, 조회만으로 업무 상태가 변경되지 않는지 검사합니다.
- 프로젝트 참여자의 기밀 권한 회수·외부인 접근·종료 상태·초안 제목 보호를 검사합니다.
- 승인본 검색·페이지 이동·보관, 이전 배포 원본 보존, 화면 경로와 실제 ZIP 항목의 일치를 검사합니다.
- 20건 이력 밖의 원시험·부적합 직접 연결, 다른 프로젝트 조회 차단, 적합 후보의 원시험·현재 구성 일치를 검사합니다.
- 실제 Chromium에서 역할별 전체 업무 흐름과 데스크톱·모바일 공통 헤더를 확인합니다.
